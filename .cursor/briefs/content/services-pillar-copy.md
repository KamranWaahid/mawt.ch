## Framework applied (per brief 00 + content quality bar)

### SEO structure per pillar page
- **H1** : 1 only, contains primary keyword (Google Ads validated, see batches 1-8)
- **H2s** : capture secondary keywords + structure narrative
- **Meta title** : ≤60 chars, includes family + "MAWT"
- **Meta description** : ≤155 chars, value prop + CTA verb

### Copywriting framework
- **PAS** (Problem-Agitate-Solution) for intro paragraphs
- **Value over features** : "vous obtenez X" before "on fait Y"
- **Social proof** : real MAWT clients mentioned (UN, Sotheby's, Mellender, Crown, Légumes…) when relevant to family

### Voice (per brief 00)
- FR : direct, anti-corporate, à taille humaine, suisse
- EN : direct, senior humans, AI-fluent, premium-but-accessible
- ❌ Forbidden : PowerPoint, usine à gaz, petite équipe, agence digitale, hire/freelance (F4)
- ✅ Validated : à taille humaine, problem solver, senior humans, dedicated, Geneva-based, intermédiaires/couches (en négatif)
